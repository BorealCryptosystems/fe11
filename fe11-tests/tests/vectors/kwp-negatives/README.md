# AES key wrap with padding

Exact public key, plaintext and envelope from RFC 5649 section 6, first example.
R. Housley and M. Dworkin. Copyright (c) 2009 IETF Trust and the persons
identified as the document authors. Source: https://www.rfc-editor.org/rfc/rfc5649.html#section-6

The complete native control must succeed before a permission or template is
changed. No alternative IV or round-trip-only oracle is used.
