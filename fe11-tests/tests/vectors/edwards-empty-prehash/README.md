# Empty context with prehash EdDSA

The public RFC8032 keys and empty messages are used with Ed25519ph/Ed448ph.
Expected signatures are independently generated by PyCryptodome3.23.0.
Each Session/AdvancedSession case sends the empty context as Some(empty) and
None. The original message is passed unchanged; prehash is requested from the
native mechanism. These are generated references, not RFC-published signatures.
Published keys are public test data. RFC8032 copyright2017 IETF Trust and the
persons identified as authors; https://www.rfc-editor.org/rfc/rfc8032.
