# RSA-OAEP wrapping and binary labels

Public Wycheproof RSA material is reused under its retained Apache-2.0 notice.
The native wrapping envelope is decoded by independent integer RSA and RFC 8017
OAEP decoding before the case may pass. Native Unwrap reads back the public
fixture secret. The negative changes only the final label byte, preserving the
embedded zero. GENERAL_ERROR is the pinned module's observed-source refusal;
it does not prove absence of a native creation effect. Cleanup has its own verdict.
