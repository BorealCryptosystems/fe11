# Truncated SHA-512 and SHAKE known answers

SHA-512/224 and SHA-512/256 retain byte-aligned NIST ACVP messages and published
digests. SHAKE128 and SHAKE256 use the NIST empty-message worked examples at
the 32-byte and 64-byte prehash widths. The manifest identifies the source and
exact extraction. No expected result is generated by the component under test.
