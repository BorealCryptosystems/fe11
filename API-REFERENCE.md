# Fe11 0.1.1 API reference

The API reference is generated by Rustdoc directly from the public Fe11 0.1.1 sources and the unchanged 0.1.0 companion packages. It provides searchable public modules, structures, enums, traits, functions and methods, with signatures and their documentation, associated types, errors and Safety contracts.

The [versioned API website](https://borealcryptosystems.github.io/fe11/0.1.1/api/index.html)
provides direct HTML navigation and search.

The four crate indexes below are relative to `0.1.1/api/`:

| Crate | Version | HTML entry | Content |
| --- | --- | --- | --- |
| `fe11` | 0.1.1 | `fe11/index.html` | High-level PKCS#11 API and resource owners |
| `fe11-sys` | 0.1.0 | `fe11_sys/index.html` | Raw constants, C types and function tables |
| `fe11-verify-engine-api` | 0.1.0 | `fe11_verify_engine_api/index.html` | Verification-component ABI, requests and callbacks |
| `fe11-verify-engine` | 0.1.0 | `fe11_verify_engine/index.html` | Component discovery entry point |

## Navigating the Fe11 API

| Area | Starting declarations |
| --- | --- |
| Module loading and discovery | `Module`, `ModuleBuilder`, `InterfaceInventory`, `ModuleProvenance` |
| Initialization and shared use | `InitializationOptions`, `NativeConcurrency`, `RuntimeOwner` |
| Sessions and authentication | `Session`, `AdvancedSession`, `SecretPin` |
| Native objects and creation | `NativeObjectRef`, `ManagedObjectRef`, `CreatedObjects` |
| Attributes and observations | `StandardAttribute`, `ObjectObservationPlan`, `MechanismObservationPlan` |
| Resource admission | `ResourceAdmission`, `SessionAdmission`, `AdmissionCancellation` |
| Results and diagnostics | `Error`, `RejectionReason`, `BusyReason`, `UnsupportedReason` |
| Recovery and persistence | `ModuleDrain`, `RecordLimits`, `StreamProgress` |
| Software verification | `VerifyEngine`, `VerifyEngineBuilder`, `VerifyEngineInfo` |

Use Rustdoc's search for a declaration or method name. Type pages group methods and trait implementations; source links open the corresponding public Rust source. The [API guide](GUIDE.md) explains workflows, while [usage contracts](CONTRACTS.md) and [coexistence](COEXISTENCE.txt) cover cross-cutting behavior.

## Building the reference

From the Fe11 workspace, with dependencies resolved:

```text
cargo doc -p fe11 -p fe11-verify-engine-api --no-deps
```

From the Fe11-sys repository:

```text
cargo doc --no-deps
```

For the engine, configure the [native build prerequisites](verify-engine/README.md), then run:

```text
cargo doc -p fe11-verify-engine --no-deps
```

Cargo writes each crate's reference under `target/doc`. Documentation builds process public source declarations and dependency/build prerequisites. The distributed reference is generated for Windows x86_64 MSVC; the [platform profiles](BUILDING.txt) specify the corresponding Linux and Windows ABI layouts.
